# hand-gesture-controller
Real-time HCI using MediaPipe Tasks API to track 21 hand landmarks. Converts raw pixels to wrist-relative vectors for translation invariance. Employs a Scikit-Learn Soft Voting Ensemble (SVM, Random Forest, Gradient Boosting) for 100% accurate gesture recognition. Features a 2s noise-gated state machine for dynamic L/R media swipe tracking.
